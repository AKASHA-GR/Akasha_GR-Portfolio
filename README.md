# 🌐 Professional Portfolio Website - Akasha G R

A responsive, modern portfolio website to showcase personal skills, projects, and contact information.

## 🚀 Features

- **Responsive Layout**: Works on mobile, tablet, and desktop devices.
- **Theme Toggle**: Light and Dark mode for better accessibility.
- **Interactive Sections**:
  - **About**: Academic background and areas of interest.
  - **Skills**: Technical, Tools & Platforms, and Soft Skills.
  - **Projects**: Mini and Major projects with modal-based detailed views.
  - **Contact**: Email, phone, LinkedIn, GitHub, and a contact form.
- **Downloadable Resume** button.
- **Contact Form** powered by EmailJS.

## 🛠️ Tech Stack

- **HTML5** for structure
- **CSS3** (custom styles / Tailwind optional) for styling
- **JavaScript (Vanilla)** for interactivity
- **EmailJS** for sending contact form messages
